# INA226 电池监测模块 — 选购与接线要点

> 状态：**2026-11-04 已确认型号，待下单**。模块到手并实测通过后，再做固件与系统页改动。
> 参考实拍：`INA226_1.jpg`（引脚说明 + 尺寸）、`INA226_2.jpg`（正反面实拍）

## 1. 选定的模块

| 项 | 值 |
| -- | -- |
| 芯片 | INA226（丝印 `S8 TI 226`） |
| 板尺寸 | **20 × 21 mm** |
| 分流电阻 | **R100 = 0.100 Ω**（丝印编码，R 为小数点） |
| 引脚 | 左侧 8 pin：`IN+ / IN- / VBS / ALE / SCL / SDA / GND / VCC`；右侧 3 个大接线孔 |
| 板载其他 | `103` 贴片 = 10 kΩ（I²C 上拉）、`E20` 电容；背面焊盘 `A1 / VCC / A0`（地址跳线） |
| I²C 地址 | 默认 **0x40**（与触摸 FT6336U 的 0x38 不冲突） |

**关键：R100 是 0.1Ω 而不是常见的 0.002Ω，到手可直接使用，不需要吹焊更换分流电阻。**

## 2. 量程与精度（由 0.1 Ω 决定）

INA226 分流电压满量程固定 ±81.92 mV：

```
电流上限   = 81.92mV / 0.1Ω = ±819 mA
电流分辨率 = 2.5µV  / 0.1Ω = 25 µA
```

本机实际电流（电池侧，按实测功耗推算）：

| 状态 | 电流 | 占量程 | 测量是否准确 |
| -- | -- | -- | -- |
| 熄屏待机 | ~20 mA | 2.4% | ✅ 800 LSB，准确 |
| 亮屏 + WiFi | ~250 mA | 30% | ✅ 准确 |
| 峰值 | ~350 mA | 43% | ✅ 准确 |
| **充电中** | **1 ~ 2 A** | **> 100%** | ⚠️ **超量程，读数顶格** |

⚠️ **已知限制**：IP5306 模块的充电电流 1~2 A，超过 819 mA 量程，充电时电流读数会顶格不准。
- **不会损坏芯片**（共模输入 ±40 V，带保护），超量程后恢复正常
- **`bus_voltage`（电池电压）与放电电流始终准确**——`bus_voltage` 是独立 ADC，量程 0~40.96 V
- 「正在充电」可凭 **读数顶格 + 符号方向** 判断
- 若需要精确充电电流：下单时可问卖家**是否有 R020 / R050 版本**；没有就接受该限制

## 3. 焊接前必查两项

### ① VBS 与 IN+ 是否板上连通

`bus_voltage` 读的是 **VBS 引脚**，不会自动等于 IN+。部分模块已板上短接，部分需要飞线。

**做法**：焊排针前用万用表蜂鸣档测 `VBS` 与 `IN+`。
- 通 → 直接按 3 个大孔接线即可
- 不通 → 补一根短线把 `VBS` 接到 `IN+`，否则电压读数会为 0 或乱跳

### ② 排针高度

左侧 8 pin 直插排针高度约 **8.5 mm**，安装位净高只有 **10 mm** → 能装但贴顶。
若压线或顶壳：换弯针（约 2 mm）或直接焊线不装针。

## 4. 安装位置与接线

安装位：电源模块旁 **35 × 20 × 10 mm** 空闲区。板 20 × 21 mm **横放可容纳**（21 沿 35 方向、20 沿 20 方向）。

**接在电池正极与 IP5306 B+ 之间（high-side）**：

```
电池红线 ──→ IN+ ──→ [R100 分流] ──→ IN- ──→ IP5306 B+
                                    VBS ──→ IN+（板上未连则飞线）
GND  ──→ 公共地
SCL  ──→ GPIO6（现有 touch_i2c）
SDA  ──→ GPIO7（现有 touch_i2c）
VCC  ──→ 3.3V
```

- **零新增 GPIO**：复用现有 I²C 总线（GPIO6/7，100 kHz）
- 背面 `A0 / A1` 焊盘保持不跳；将来加第二块测 5V 负载侧时，把 A0 跳上改为 **0x41**，两块可共总线

## 5. 固件配置草案（目前不写入，等实测后启用）

```yaml
sensor:
  - platform: ina226
    address: 0x40
    shunt_resistance: 0.1 ohm     # R100
    max_current: 0.8A             # 必须匹配：0.8 × 0.1 = 80mV < 81.92mV
    adc_time: 1100us
    adc_averaging: 64             # 压 mA 级噪声
    update_interval: 10s
    bus_voltage: { id: batt_voltage, name: "Battery Voltage" }
    current:     { id: batt_current, name: "Battery Current" }
    power:       { id: batt_power,   name: "Battery Power" }
```

⚠️ **不要照抄 ESPHome 官方示例**：官方默认 `shunt_resistance: 0.1 ohm` + `max_current: 3.2A`，二者相乘 320 mV 远超 81.92 mV 满量程，实际会削顶。`max_current` 与分流电阻必须满足 `max_current × shunt_resistance ≤ 81.92 mV`。

## 6. 到手后的验证顺序

1. 万用表测 `VBS ↔ IN+` 通断（决定要不要飞线）
2. 只接 I²C + VCC/GND，**不串入主回路**，扫描地址应出现 `0x40`
3. 串入电池回路，对比万用表实测电压与 `bus_voltage` → 误差应 < ±10 mV
4. 对比实测电流与 `current` → 熄屏时应约 20 mA、亮屏 200~300 mA
5. 以上通过后，再改固件与系统页

## 7. 为什么值得装

- **`bus_voltage` 直接给出电池真实电压**，取代原计划的「100k/100k 分压 + ADC」方案——省掉分压电阻、省掉 ADC 非线性标定、零新增 GPIO
- **`power` 由芯片直接算好**（电压 × 电流），可用于真实续航推算，取代目前靠 HA 侧推断的「低电量」
- **IP5406 回板验收时**，可观察拔适配器瞬间电池侧电流的跳变，比「看屏幕是否重启」精确
- 代价：常耗 0.33 mA，相对 20 mA 待机 +1.6%（续航约少 1.5 小时）
