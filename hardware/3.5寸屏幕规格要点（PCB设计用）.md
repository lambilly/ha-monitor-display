> "3.5 TFT SPI 480x320 V1.0 Capacitive Touch"）。
> 本文是把四张图蒸馏后的硬件设计要点，配合《硬件焊接接线指南.md》使用。

## 三、14 针引脚定义（与焊接指南逐针核对一致 ✔）

VCC / GND / LCD_CS / LCD_RST / LCD_RS(DC) / MOSI / SCK / LED / MISO /
CTP_SCL / CTP_RST / CTP_SDA / CTP_INT / SD_CS

PCB 网络表建议（对齐固件引脚，勿改）：

```
VCC──5V轨    GND──GND     LCD_CS──GPIO10   LCD_RST──GPIO8
LCD_RS──GPIO9             MOSI──GPIO11     SCK──GPIO12
LED──GPIO15(PWM 20kHz)    MISO──GPIO13
CTP_SCL──GPIO6            CTP_SDA──GPIO7   CTP_RST──GPIO5
CTP_INT──NC(可选)         SD_CS──GPIO4 + 10kΩ上拉到3.3V
```

## 四、打 PCB 的设计清单

**布局**
- [ ] 屏幕排针放板边，SPI 四线（MOSI/MISO/SCK/CS）走线 <8cm，两侧 GND 包地（SCK 40MHz）
- [ ] TF 卡槽（屏板上自带）不用在 PCB 复刻，SD_CS 上拉电阻放 PCB 靠排针处
- [ ] I2C（CTP_SCL/SDA）走线远离 SPI；模组板载上拉已存在，PCB 不必再加（留 0Ω 备用位即可）
- [ ] 4 个 φ3.0 定位孔与外壳铜柱对位，开窗 ≥ 49.96 × 74.44 mm

**电源（v3.0 硬件版重点）**

- [ ] 5V 轨进线用 XH2.54-2P 端子（不用 USB 口，按用户要求）
- [x] **方案已定（2026-11-03）**：**IP5406**（英集芯，IP5306 升级版）已设计下单；
  ESOP8、单电感充放电、2.0A 充电 / 2.4A 放电、内置功率 MOS。电池座 JST-PH2.0
  - 相对 IP5306 的三点改进：① 内置电源路径管理，标称支持边充边放；② **输出固定常开 5V**
    （不因轻载自动关断，省掉「定期模拟按键」的土办法）；③ 待机功耗 <150µA
  - 负载核算：背光 95mA + ESP32-S3 WiFi 峰值 ~350mA + 余量 ≈ **500mA @5V**，
    相对 2.4A 输出余量充足
- [ ] ⚠ **必须实测的遗留风险：IP5406 不等于「零中断」**
  IP5xxx 系列本质是移动电源 SOC，VIN 插入/拔出时靠内部 MOS 重排做路径切换，
  切换瞬间 5V 会短时跌落。IP5306 上这是**已知且被官方文档明确记载**的现象
  （「拔掉适配器会短暂掉电，可能导致后端 MCU 重启」），社区实测加电解电容也不一定解决。
  IP5406 标称改进路径管理，但**属于同一架构**，不能假定它没有跌落
  - **验收标准**：充电状态下拔掉适配器，屏幕**不得重启**（连试 5 次，看 ESPHome uptime
    是否归零），且不得出现花屏/触摸失灵
  - 若不达标，按成本从低到高加码：① 5V 轨电容 470µF → **1000µF 低 ESR** 并尽量贴近负载；
    ② VOUT 与 SW 之间加 TVS/肖特基做旁路（跳过 IC 直供，有专利先例）；
    ③ 换 **NVDC** 方案 BQ25606（SYS 轨由单一变换器持续供电，切换无跌落），
    代价是外围器件多、需 MT3608 升压
- [ ] 5V 轨靠近屏排针处放 470µF 低 ESR 电解 + 100nF 陶瓷（宁大勿小，见上条）
- [ ] **KEY 引脚必须处理**：IP5406 单击开输出、双击关输出。板上要有按键，或把 KEY
  按常开方式接（否则电池装好后设备起不来，或误触双击就断电）
- [ ] 充电电流按电池容量确认：IP5406 默认充电电流偏大（约 2A），小容量电池需改
  PROG/RSET 限流，否则电池发热、循环寿命下降
- [ ] 电池 NTC 接到 IC（IP5406 支持 NTC 温度保护），贴在电芯侧面
- [ ] 3.3V 由开发板 LDO 供给即可（屏幕信号经板载电平转换，PCB 不做 5V→3.3V 逻辑）

**工艺**
- [ ] 板厚 1.6mm，2 层足够；沉金（排针/FPC 触点可靠性）
- [ ] 屏排针建议**母座 2×7 2.54 双排**或单排座，方便返修换屏

## 五、遗留核对项

- [ ] 定位孔精确坐标（参数4 图右下角小图，放大复核后再画外壳）
- [ ] FPC 14P 反向座是否要上 PCB（当前排针方案够用，FPC 留给后续紧凑版）
- [ ] 模组板载 LDO 发热量：5V 直供时 0.5W 背光 + 静态，外壳内注意通风
