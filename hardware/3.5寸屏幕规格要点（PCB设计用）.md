## 三、14 针引脚定义（与焊接指南逐针核对一致 ✔）

VCC / GND / LCD_CS / LCD_RST / LCD_RS(DC) / MOSI / SCK / LED / MISO /
CTP_SCL / CTP_RST / CTP_SDA / CTP_INT / SD_CS

PCB 网络表建议（对齐固件引脚，勿改）：

```
VCC──5V轨    GND──GND     LCD_CS──GPIO10   LCD_RST──GPIO8
LCD_RS──GPIO9             MOSI──GPIO11     SCK──GPIO12
LED──GPIO15(PWM 20kHz)    MISO──GPIO13
CTP_SCL──GPIO6            CTP_SDA──GPIO7   CTP_RST──GPIO5
CTP_INT──NC(可选)         SD_CS──GPIO4 + 10kΩ上拉到3.3V
```

## 四、打 PCB 的设计清单

**布局**
- [ ] 屏幕排针放板边，SPI 四线（MOSI/MISO/SCK/CS）走线 <8cm，两侧 GND 包地（SCK 40MHz）
- [ ] TF 卡槽（屏板上自带）不用在 PCB 复刻，SD_CS 上拉电阻放 PCB 靠排针处
- [ ] I2C（CTP_SCL/SDA）走线远离 SPI；模组板载上拉已存在，PCB 不必再加（留 0Ω 备用位即可）
- [ ] 4 个 φ3.0 定位孔与外壳铜柱对位，开窗 ≥ 49.96 × 74.44 mm

**电源（v3.0 硬件版重点）**
- [ ] 5V 轨进线用 XH2.54-2P 端子（不用 USB 口，按用户要求）
- [ ] **把电源方案做进板**：BQ25606（NVDC 电源路径，拔线不断电）+ MT3608 升压 5V，
  电池座 JST-PH2.0。系统负载核算：背光 95mA + ESP32-S3 WiFi 峰值 ~350mA
  + 余量 ≈ **500mA @5V**（原按 200mA 背光估的 550mA 可下调）
- [ ] 5V 轨靠近屏排针处放 470µF 低 ESR 电解 + 100nF 陶瓷
- [ ] 3.3V 由开发板 LDO 供给即可（屏幕信号经板载电平转换，PCB 不做 5V→3.3V 逻辑）

**工艺**
- [ ] 板厚 1.6mm，2 层足够；沉金（排针/FPC 触点可靠性）
- [ ] 屏排针建议**母座 2×7 2.54 双排**或单排座，方便返修换屏

## 五、遗留核对项

- [ ] 定位孔精确坐标（参数4 图右下角小图，放大复核后再画外壳）
- [ ] FPC 14P 反向座是否要上 PCB（当前排针方案够用，FPC 留给后续紧凑版）
- [ ] 模组板载 LDO 发热量：5V 直供时 0.5W 背光 + 静态，外壳内注意通风
