# IP5406 最小电源板设计方案

> 替换 IP5306 电源板，解决"充电时拔掉电源 → 断电重启"问题
> 版本 V1.0 ｜ 2026-11-03

---

## 1. 为什么 IP5406 能解决你的问题

| 特性 | IP5306（现用） | IP5406（新方案） |
|---|---|---|
| 电源路径管理 | 无（充电和放电共用一套，切换靠检测） | **内置路径管理，边充边放**，插电时负载由输入直供，拔电无缝切电池 |
| 拔掉输入电源 | 需要重新检测负载、启动升压，有掉电窗口 → 单片机重启 | 路径切换为硬件设计目标，**无缝切换** |
| 轻载自动关机 | 有（<50mA 约 32s 关机，需 KEY 脚保活） | **5V 固定常开输出**，轻载只关 LED 进休眠（待机 <150µA），不关输出 |
| 充电能力 | 2A | 2A，自动适配适配器输出能力 |
| 放电能力 | 2.4A | 2.1A / 2.4A，效率最高 93% |
| 保护 | 过充/过放/过流/过温 | 同样齐全 + 输入过压(5.6V) + NTC 温度检测（KEY 复用） |

结论：换 IP5406 是对的，硬件上直接消除断电重启，软件也不用再做 KEY 保活。

**⚠️ 采购说明（已核实修正）**：IP5406 / IP5406T / IP5407 三者为同家族 ESOP8 芯片，封装、引脚、参数一致（2A 充 / 2.4A 放、边充边放、5V 常开），均可直接换在 IP5306 板上，哪个便宜买哪个。已知差异：IP5406T 据实测不支持外接 NTC（仍有内置芯片过温保护）。注意：部分资料站把 IP5389（QFN64 百瓦快充）/IP5356（QFN40）的手册错标为"IP5406T"，选购时认准 **ESOP8 / SOP-8-EP（3.9×4mm 带散热焊盘）封装**即可。

## 2. 系统框图 / 接口定义

全部为两线制，无 USB 口（与 KiCad 工程位号一致）：

```
J1（右侧 6 针 2.54，1:1 复刻原 IP5306 模块）
    1 OUT-5V  5V 输出正（经 J4 开关座）
    2 GND     公共地
    3 BAT     锂电池正极 3.7–4.2V（与 J3-1 并联）
    4 GND     公共地
    5 GND     公共地
    6 VIN     5V 充电输入 4.65–6V

J2（左侧 4 针 2.54，备用）
    1 DCP（引出到 J2-1，默认悬空） 2 KEY（NTC/按键） 3 LED1  4 LED2

J3（PH2.0 2P 母座，电池直插）
    1 BAT  2 GND

J4（2 针 2.54，外接开关，双针在 2.54 网格）
    1 VOUT（芯片侧）  2 OUT_SW（负载侧，接 J1-1）
```

J1 六针 + J2 四针 + J4 两针共 12 个焊盘**全部落在同一个 2.54 mm 网格**上，
整板可直接插标准洞洞板；J3 是 2.0 mm 间距的电池座，不参与洞洞板焊接。

### J4 外接电源开关（可选，串在输出线上）

用途：外接一个面板开关控制设备供电；不用开关时插短接帽即常输出。

```
U1 第8脚 VOUT ──┬── C3/C4/C5 ── GND  （输出电容留在芯片侧）
                │
               J4 (2.54 2P)
                │
              J1-1 OUT-5V ──→ 负载
```

- 外接开关插 J4：开=供电，关=断电；关断后芯片进待机 <150µA，电池几乎不掉电
- 不用开关：J4 插 2.54 短接帽，常输出，功能与原设计完全一致
- 充电路径走 BAT（J3 / J1-3），不受此开关影响，断电状态下照常充电
- ⚠️ 不要把外接开关接到 KEY 脚：KEY 是"按下事件"语义（短按/长按/双击），拨动开关常闭会芯片被判为持续长按，行为不可控
- 电流注意：XH2.54 额定约 3A，负载峰值 ≤2.4A 没问题；C3/C4 必须留在 J4 芯片侧（开关之前）

## 3. 引脚连接（ESOP8，对照数据手册 Fig.1）

| 引脚 | 名称 | 连接 |
|---|---|---|
| 1 | VIN | 接 J1 正极；C1 22µF 就近接地 |
| 2 | DCP | 本板无 USB-A 口，**已连通到 J2-1 引出，默认不接（等效悬空）** |
| 3 | KEY | 轻触按键到 GND（可选）；复用 NTC，需温度保护时接 10K NTC 到 GND |
| 4 | LED1 | 电量指示 LED（可选） |
| 5 | LED2 | 电量指示 LED（可选） |
| 6 | BAT | 接 J2 电池正极；C2 10µF 就近接地 |
| 7 | SW | 接功率电感 L1 一端 |
| 8 | VOUT | 接 J4-1（经开关到 J1-1）；C3、C4 2×22µF 就近接地 |
| PAD | 散热焊盘 | **必须接地**，开窗 + 过孔阵列 |

功率级唯一电感：L1 接在 SW 与 BAT+ 之间（单电感完成降压充电 + 升压放电）。

## 5. 关键参数（摘自数据手册）

- 输入电压 VIN：4.65–6V（推荐 5V），输入过压保护 5.6V
- 充电：最大约 1.9A，涓流 100mA（<3V），CV 4.20V（支持 4.35V 电池配置），充满截止，24h 充电超时保护
- 放电：电池工作 3.0–4.4V，放电截止 2.95V
- 输出：5.0–5.25V 空载；4.75–5.15V @2.1A；过流保护 2.8A；纹波 <100mV
- 待机：<150µA（轻载关 LED 不关输出）

## 6. PCB 设计要点（2 层板，建议 12×18 ~ 15×20 mm）

1. **功率回路最短**：BAT → L1 → SW → 芯片 → VOUT → GND。L1 紧贴芯片 6/7 脚，这条环路越短 EMI 和压降越小。
2. **散热焊盘**：底部 PAD 全开窗，打 4~9 个 Ø0.3 过孔到背面地，背面整块铺铜。
3. **线宽**：BAT/SW/VOUT/GND 主电流路径 ≥1.5mm（2A 余量），最好整片铺地。
4. **地处理**：输入电容、输出电容、芯片 PAD 的地就近过孔汇入主地层，避免细长地线。
5. **去耦电容贴近引脚**：C1 贴 VIN，C2 贴 BAT，C3/C4 贴 VOUT，先过电容再走线。
6. **小信号远离 SW**：KEY、LED 走线离 SW 开关节点 ≥2mm，防止耦合误触发。
7. **接插件布局**：J1/J2 摆两侧板边，J3 电池座探出板底、J4 开关座放板底左侧；J3 座体朝板外便于插拔。

## 7. 焊接与调试步骤

1. 嘉立创下单 PCB（2 层 1.6mm 或 1.0mm 更省空间），SMT 贴 U1、L1、电容；接插件手焊或一起贴。
2. **先不接电池**：J1-6(VIN)/J1-2(GND) 接 5V，测 J4-1 与 J1-1 应有 5V 输出（无电池也能带载，路径管理直供）。
3. 接入电池（先给电池预充一点点电，>3V），测充电电流约 1.9A、充满后 4.2V。
4. **关键测试（你的原始问题）**：J1-6 供电 + 带载状态下，反复拔插输入线，用示波器看 J1-1 电压——波动应小于一个毫秒级凹坑，单片机不重启。
5. 电池单独供电，轻载（几十 mA）放置 1 分钟以上，确认输出**不关断**（这是与 IP5306 的本质区别）。
6. 短路 J1-1 与 J1-2，确认过流保护动作，解除后恢复。
7. J4 插短接帽时输出正常；插外接开关测试开/关功能，确认关断后待机电流 <150µA。
8. J3 插电池包，确认 BAT 直插供电正常（与 J1-3 焊线两种方式并联，可任选一种）。

## 8. 注意事项

- 电池务必用**带保护板（PCM）的电芯**或成品 18650/聚合物电池，芯片的过放保护（2.95V）是最后防线，不建议裸芯直连。
- 充电+带载同时进行时，输入 5V/2A 的功率由负载和充电自动分配，负载重时充电变慢属正常。
- 输出若还要更平稳，可在 J1-1 处再并一颗 100µF 聚合物电容（可选，一般不需要）。
- 若你的钻孔设备有感性负载（电机），在设备端并 0.1µF + TVS 更稳妥。

目标：新 IP5406 板与市售 IP5306 模块（优信电子 25×16mm 版）引脚完全一致，拔插即可无缝升级。

### 9.1 原 IP5306 板实测信息（根据照片）

- 板尺寸：25mm × 16mm
- 右侧一排 6 个 2.54mm 镀金通孔焊盘，背面丝印从上到下：

| 序号 | 丝印 | 功能 | 新板连接 |

| 1 | OUT-5V | 5V 输出正极 | U1 VOUT（经可选 J4 开关座） |

- 其他复刻要素：KEY 焊盘+按键位（左下）、4 颗电量 LED（25/50/75/100%，由 IP5306 的 3 个 LED 驱动脚 LED1/LED2/LED3 经 100Ω 电阻驱动）、1R0 电感位；底边疑似有 Micro-USB 口（以实物为准，有无均不影响引脚兼容，输入走 VIN/GND 焊盘）

### 9.3 备选路线：在原 IP5306 板上直接换芯片

**⚠️ 重要修正（2026-11-03 核实）**：IP5406 与 IP5306 只是**同封装（ESOP8）**，**引脚定义并不相同**：

| 引脚 | IP5306 | IP5406 | 是否相同 |
|---|---|---|---|
| 1 | VIN | VIN | ✅ |
| 2 | LED1 | DCP | ❌ |
| 3 | LED2 | KEY | ❌ |
| 4 | LED3 | LED1 | ❌ |
| 5 | KEY | LED2 | ❌ |
| 6 | BAT | BAT | ✅ |
| 7 | SW | SW | ✅ |
| 8 | VOUT | VOUT | ✅ |
| PAD | GND | GND | ✅ |

只有功率路径（1/6/7/8/PAD）位置相同；中间 4 个控制脚完全不同——IP5306 有 **3 个** LED 驱动脚（LED1/LED2/LED3）+ KEY，IP5406 只有 **2 个**（LED1/LED2）+ DCP + KEY。

**因此不能把 IP5406 直接焊上原板当成品用**：功率部分能工作，但原板 pin2/3/4/5 上挂的是 LED 驱动电路和按键网络，换芯后：
- IP5406 的 pin2(DCP) 会接到原 LED1 电路、pin3(KEY) 接到原 LED2 电路 → **KEY 可能被 LED 网络持续拉低，触发长按逻辑把输出关掉**，恰好毁掉你要的常开输出
- pin4/pin5(LED1/LED2) 接到原 LED3/按键网络 → 指示灯全乱

**若仍想用原板验证，必须先把 pin2~pin5 的外围断开**（拆掉 4 颗 LED 和按键，或割断这几条走线），只保留 1/6/7/8/PAD 的功率路径，再换芯片。这样能验证"拔插不重启、轻载不关机"的核心效果，只是没有电量显示。

**准备**：IP5406 芯片 2~3 颗（立创商城/淘宝搜"IP5406 ESOP8"，IP5406T、IP5407 同样可用）、热风枪、电烙铁、助焊剂、镊子、洗板水或酒精棉片。

**第 0 步（必做）**：拆掉原板 4 颗 LED 与按键，或用刀片割断 U1 pin2/3/4/5 引出的走线，确保这 4 个脚悬空。

**拆除 IP5306**：
1. 板上电池和输入线全部断开
2. 芯片四周引脚和底部涂足助焊剂
3. 热风枪 330~350°C、中风，绕芯片四周引脚均匀打圈加热（约 30~60s），镊子轻推芯片感觉引脚变软后垂直夹起，切忌硬撬
4. 立即用烙铁+吸锡带清理引脚焊盘上的残锡，垫平焊盘（重点是底部散热焊盘区），酒精擦净

**焊接 IP5406**：
1. 先在底部散热焊盘点少量锡或涂焊膏
2. 芯片第 1 脚圆点对准原第 1 脚位置（对不上就看引脚：1 VIN / 2 DCP / 3 KEY / 4 LED1 / 5 LED2 / 6 BAT / 7 SW / 8 VOUT，对照板上走线确认 BAT、SW、VOUT 位置）
3. 先用烙铁点焊对角两个引脚固定，微调对齐后，热风枪低温快吹使底部焊盘着锡，最后补焊四周引脚并检查连锡

**验证**：
1. 接电池（>3V），空载测 OUT-5V 应有 5V
2. 接 5V 输入带载，反复拔插输入线，负载不重启即成功
3. 轻载（几十 mA）放 1 分钟以上，输出不断（IP5306 时代 32s 就关）
4. 摸芯片温度，温热正常、烫手说明底部焊盘未着锡，需返工

风险提示：吹焊过热可能损坏焊盘或附近元件；底部散热焊盘没焊好会过热跳保护。建议先拿一块板练手。

建议路线：直接做 1:1 兼容板（KiCad 工程已生成，见 `KiCad/` 目录）；如想先低成本验证，则按第 0 步断开 LED/KEY 网络后换芯片试。

### 9.4 IP5406 / IP5407 / IP5506 选型对比（采购须知）

| | IP5406 | IP5407 | IP5406T | IP5506 |
|---|---|---|---|---|
| 封装 | ESOP8 | ESOP8 | ESOP8 | ESOP16（引脚完全不同） |
| 充/放电 | 2A / 2.4A | 2A / 2.4A | 2A / 2.4A | 2A / 2.4A |
| 电源路径管理（边充边放） | ✓ | ✓ | ✓ | ✓ |
| 电量显示 | 1/2/4 颗 LED | 1/2/4 颗 LED | 1/2/4 颗 LED | 数码管或 1~5 颗 LED（14bit ADC+库仑计） |
| 外接 NTC | ✓（KEY 复用） | ✓（KEY 复用） | ✗（据开源项目实测，仅内置过温保护） | ✓ |
| 待机电流 | <150µA | <150µA | <150µA | <100µA |
| 空载行为 | 5V 常开 | 5V 常开 | 5V 常开 | **空载自动休眠（断输出）** |
| 能否直换 IP5306 板 | ⚠️ 需先断开 pin2~5 的 LED/KEY 网络 | ⚠️ 同左（同封装，控制脚定义不同） | ⚠️ 同左 | ✗（封装/引脚/外围全不同） |

- IP5406 / IP5407 / IP5406T 为同族 ESOP8 芯片，可互为备份，哪个便宜买哪个；想要 NTC 温度保护则优先 IP5406/IP5407
- 警示：部分资料站把 IP5389（QFN64 百瓦快充）/IP5356（QFN40）的手册错标为"IP5406T"，实购认准 ESOP8/SOP-8-EP（3.9×4mm 带散热焊盘）封装
- IP5506 虽有数码管显示和库仑计，但封装不兼容、且有空载自动休眠断输出特性，与本方案"5V 常开"诉求冲突，不买
- 省邮费建议：IP5406 / IP5407 / IP5406T 混买共 4~6 颗一单购齐，够 2~3 块板换芯验证并留备件

### 9.5 本板能否用于 IP5407？（已核实：可以，引脚完全相同）

IP5407 官方数据手册（V1.31）第 4 节 Pin definition 与 IP5406 逐字一致：

| 引脚 | 名称 | 功能 | IP5406 | IP5407 |
|---|---|---|---|---|
| 1 | VIN | 5V 充电输入 | ✓ | ✓ |
| 2 | DCP | 接 USB-A D+/D- | ✓ | ✓ |
| 3 | KEY | 按键 / 照明灯 / NTC 复用 | ✓ | ✓ |
| 4 | LED1 | LED 驱动 | ✓ | ✓ |
| 5 | LED2 | LED 驱动 | ✓ | ✓ |
| 6 | BAT | 电池正极 | ✓ | ✓ |
| 7 | SW | DC-DC 开关 | ✓ | ✓ |
| 8 | VOUT | 5V 输出 | ✓ | ✓ |
| 9(PAD) | GND | 散热焊盘接 GND | ✓ | ✓ |

结论：**本板 IP5406 / IP5407 / IP5406T 三种芯片通用**，换芯片即可，外围元件不用改
（L1=1µH、C1=22µF、C2=10µF、C3/C4=22µF、C5=100nF 均通用）。

唯一差异在**出厂灯显配置**，不影响 5V 输出与充电：

| 型号 | 默认灯显 |
|---|---|
| IP5406 | 1/2/4 灯 |
| IP5407 | 4 灯（支持 1/2/4）；`IP5407_2D1D` 才是 2/1 灯 |
| IP5406T | 1/2/4 灯（无外接 NTC） |

所以用 IP5407 标准品时，建议 D1/D2 先不焊（或按手册 Figure 1 改成 4 灯结构）；
5V 常开输出、边充边放、保护功能完全一致。
