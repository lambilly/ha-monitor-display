# IP5406 / IP5407 5V 电源板 — KiCad 工程说明（rev 1.5 定稿）

**25.00 × 16.00 mm** 两层板，与原 IP5306 模块**同尺寸、同引脚顺序**，可直接拔插替换。

- 右侧 J1（6 针 2.54）+ 左侧 J2（4 针 2.54）+ 板底 J4（2 针 2.54），**十二根针全部落在同一个 2.54 mm 网格上**，整板可插标准洞洞板
- 板底右侧新增 **J3 = PH2.0 电池母座**，电池包直接插拔
- 板上不放贴片 LED，电量灯从 J2-3 / J2-4 外接

## 2. 关键尺寸（全部对 2.54 网格）

| 项目 | 数值 | 说明 |
|---|---|---|
| 板框 | **25.00 × 16.00 mm** | 与原 IP5306 模块完全一致 |
| J1（右排 6 针）x | 123.93 | 距右板边 1.07 mm |
| J2（左排 4 针）x | 101.07 | 距左板边 1.07 mm |
| **J1 ↔ J2 间距** | **22.86 mm = 9 × 2.54** | 插洞洞板跨 9 个孔距 |
| 排内针距 / 孔径 / 焊盘 | 2.54 mm / 1.0 mm / 1.6 mm | 标准 2.54 排针 |
| J1 针 y | 101.65 / 104.19 / 106.73 / 109.27 / 111.81 / 114.35 | 上下各留 1.65 mm |
| J2 针 y | 104.19 / 106.73 / 109.27 / 111.81 | 与 J1 的 2~5 号针同处网格行 |
| **J4 针（x / y）** | **103.61 / 106.15 ，114.35** | **两针均落在 2.54 网格**，与 J1/J2 同网格 |
| J3（PH2.0 座）针 | 116.40 / 118.40 ，114.20 | 2.0 mm 间距（电池母座，不参与洞洞板焊接） |

**边距为什么是 1.07 mm**：板宽 25 mm 要同时满足"两排针落在 2.54 网格上"，
可选间距只能是 2.54 的整数倍：9 × 2.54 = 22.86（两侧余 2.14 mm），
10 × 2.54 = 25.4 已超出板宽。所以 22.86 mm 是唯一解，两侧各 1.07 mm。
焊盘 1.6 mm 时铜到板边 0.27 mm、孔到板边 0.57 mm，均在嘉立创工艺范围内。

> 插洞洞板时：J1 六针 + J2 四针 + J4 两针共 **12 个脚全部落孔**，横向占 9 个孔距。

## 3. 板级接口

**J1（右侧 6 针，与原 IP5306 模块完全一致，从上到下）**

| 序号 | 丝印 | 功能 |
|---|---|---|
| 1 | OUT-5V | 5V 输出正（来自 J4 开关座） |
| 2 | GND | 公共地 |
| 3 | BAT | 锂电池正极（3.7–4.2 V），与 J3-1 并联 |
| 4 | GND | 公共地 |
| 5 | GND | 公共地 |
| 6 | VIN | 5V 充电输入正（4.65–6 V） |

> 板上只有这一处 VIN / GND 功率针，左侧 J2 不再引出 VIN/GND。

**J2（左侧 4 针备用排针，从上到下）**

| 序号 | 丝印 | 功能 | 用途 |
|---|---|---|---|
| 1 | DCP | 芯片 DCP 脚（已连通到 U1-2，默认不接） | 预留测试点 |
| 2 | KEY | 芯片 KEY 脚 | 接 10K NTC 做电池温度保护，或接按键 |
| 3 | LED1 | 电量 LED 驱动 1 | 外接电量灯（见第 4 节） |
| 4 | LED2 | 电量 LED 驱动 2 | 外接电量灯（见第 4 节） |

**J4（2 针 2.54 通孔，板底左侧，**已卡 2.54 网格**）**
外接电源开关座，串在 VOUT 与 OUT_SW 之间。

- **pin1 = VOUT**（芯片侧，5V 常出），坐标 (103.61, 114.35)
- **pin2 = OUT_SW**（负载侧，接 J1-1），坐标 (106.15, 114.35)
- 插开关 = 可控通断；插 **2.54 短接帽** = 常输出（默认用法）
- 两针与 J1/J2 处于同一 2.54 网格 → 本板插到别的 2.54 底板上时，J4 也能同时落孔
- 距下板边 1.65 mm，短接帽/开关不干涉

**J3（PH2.0 电池母座，板底右侧）**

- pin1 = BAT（坐标 116.40, 114.20）、pin2 = GND（118.40, 114.20），**2.0 mm 间距**
- 与 J1-3(BAT)、J1-4/5(GND) 并联，**电池包直接插拔**，不用再焊线
- 座体朝板外（−y 方向）伸出板边，插头从板下方水平插入，几乎不占板面
- 两个固定脚建议一起焊到 GND（座子外壳接地，抗插拔受力）
- 注意：J3 是 2.0 mm 间距，**不在 2.54 网格上**；插洞洞板时只焊 J1/J2/J4 的针即可

## 4. 外接电量灯怎么接（J2-3 / J2-4）

板上不放贴片 LED，电量指示从 J2 引出。IP5406 的 LED1/LED2 是**开漏驱动脚**，
两灯模式下用**两颗 LED 反并联**跨接：

```
        ┌──────── J2-3  (LED1)
        │
       ─┴─►│──  D1  (阳极接 LED1，阴极接 LED2)  = 低电量档
        │
       ─┬─◄│──  D2  (阳极接 LED2，阴极接 LED1)  = 高电量档
        │
        └──────── J2-4  (LED2)
```

- **D1**：阳极 → J2-3(LED1)，阴极 → J2-4(LED2)
- **D2**：阳极 → J2-4(LED2)，阴极 → J2-3(LED1)
- 两只方向相反，芯片交替拉低其中一脚点亮对应的一颗，实现两档电量指示
- 3 mm/5 mm 直插 LED 或 0805 贴片 LED 都行，飞线到 J2-3 / J2-4 即可
- 若只要"有电就亮"一颗灯：LED 阳极经 1 kΩ 接 BAT（或 5V），阴极接 LED1，
  另一脚 LED2 悬空

> 用 IP5407 标准品（默认 4 灯配置）时，两灯反并联可能显示不符预期，
> 这时按数据手册 Figure 1 的四灯结构外接，或直接不接指示灯。

## 6. PCB 状态（rev 1.5 复检）

- 板框：25.00 × 16.00 mm，2 层，1.5 mm 厚
- 元件：**11 个**（U1、L1、C1–C5、J1、J2、J3、J4；无贴片 LED）
- 布线：**全部网络布通，ratsnest = 0**，过孔 10 个、走线 54 段
  - **F.Cu**：SW / VOUT 干线与电容支路 / BAT（U1→L1→C2）/ **DCP**（U1-2 → J2-1）/
    KEY / LED1 / LED2 / **OUT_SW 全程**（J4-2 → y=111.7 → x=122.5 竖直 → J1-1）/ GND 缝合焊盘
  - **B.Cu**：GND 整层铺铜 / VOUT → J4-1（x=103.2 左通道 → y=113.2）/
    VIN（x=102.4 → 底边 y=115.6 → 斜进 J1-6）/ BAT 到 J3（x=113.25 下落 → y=112.8）/
    BAT 到 J1-3（via 后 y≈107.5 到 J1-3）
- DRC：**0 违规、0 未连接**（按 0.2 mm 最小间隙 / 0.2 mm 铜到板边 / 0.6 mm 丝印字高
  的实际工程规则复检）；ERC：**0 违规**；网表 ↔ PCB **10 个网络全部一致**
- **OUT_SW 之所以走顶层**：它必须从板左侧横穿到 J1-1，走底层会把 GND 铺铜切成
  东西两块，J1 的 GND 针会变成孤岛。移到顶层后底层铺铜完整，J1-2/4/5 直接
  连到铺铜，不需要额外桥接线
- 板边规则：`IP5406_PSU.kicad_dru` 把"铜到板边"约束设为 **0.2 mm**（嘉立创下限），
  因为 25 mm 宽 + 2.54 网格排针必然让焊盘铜皮距边 0.27 mm

## 6.1 正面丝印装配标记（rev 1.5 新增）

全部在 **F.Silkscreen**（正面），线宽 0.12 mm，字高 0.65–0.70 mm。板子从正面看时：

| 标记 | 位置 / 内容 | 说明 |
|---|---|---|
| **U1 本体框** | x 107.75–111.85，y 105.70–110.70 | ESOP8 本体轮廓，**左上角削角 0.7 mm = 缺口标志** |
| **U1 pin1 点 + "1"** | 实心圆点 (108.25, 105.30)、数字 "1" (109.15, 105.05) | 都在本体框**外面**，芯片焊好后仍看得见；削角 + 圆点都指向 **pin1 = VIN（左上）**，右上角是 pin8 = VOUT |
| **L1 本体框** | x 113.60–118.80，y 105.50–109.30 | 电感轮廓，左上角同样削 0.5 mm 缺口，指向 **pad1 = SW（左侧）**；电感本身无极性，缺口只用于对齐方向 |
| **C1 / C3 / C4 极性** | "+" 在 pad1 正上方（x = 103.7 / 110.3 / 113.7，y = 101.45），"−" 在 pad2 正上方（x = 105.5 / 112.1 / 115.5） | pad1 = VIN 或 VOUT 正端，pad2 = GND |
| **C2 极性** | "+" (119.50, 110.75)、"−" (121.30, 110.75) | pad1 = BAT 正端，pad2 = GND；在电容下方避开上方 BAT 走线 |
| **J3 极性** | "+" (116.40, 112.75)、"−" (118.40, 112.75) | PH2.0 电池母座 pad1 = BAT+、pad2 = GND−，插电池前先看这两个符号 |
| **C5 不标** | 100nF MLCC 无极性 | 刻意不画 +/-，避免误导 |
| 背面丝印 | B.Silkscreen | J1 六针名称（OUT-5V/GND/BAT/GND/GND/VIN）+ 标题 `IP5406 5V UPS / Lambilly @2026.11` |

> 贴片 MLCC（0805）本身无极性，"+" 只是标明该焊盘接的是电源正端（VIN/VOUT/BAT），
> 方便用万用表核对；如果换成钽电容/电解电容，就按 "+" 装，不要再对调。
> 单看丝印检查芯片方向：**缺口 + 圆点 = pin1（VIN）那一角**，与 J1-6 (VIN) 同一侧。

## 7. 芯片兼容性（重要）

**IP5406 与 IP5407 引脚完全相同**（官方数据手册 Pin definition 一致）：

| 引脚 | 名称 | 功能 |
|---|---|---|
| 1 | VIN | 5V 充电输入 |
| 2 | DCP | USB-A D+/D- 识别（不用则悬空） |
| 3 | KEY | 按键 / 照明灯 / NTC 复用 |
| 4 | LED1 | 电量 LED 驱动 |
| 5 | LED2 | 电量 LED 驱动 |
| 6 | BAT | 电池正极 |
| 7 | SW | DC-DC 开关（接电感） |
| 8 | VOUT | 5V 升压输出 |
| 9 (PAD) | GND | 散热焊盘接 GND |

→ **本板 IP5406 / IP5407 / IP5406T 通用**，直接换芯片即可，无需改板。

**与 IP5306 不同**（不能直接互换芯片，控制脚 2~5 定义不同）：

| 引脚 | IP5306 | IP5406 / IP5407 |
|---|---|---|
| 1 | VIN | VIN ✅ |
| 2 | LED1 | DCP ❌ |
| 3 | LED2 | KEY ❌ |
| 4 | LED3 | LED1 ❌ |
| 5 | KEY | LED2 ❌ |
| 6/7/8 | BAT/SW/VOUT | 相同 ✅ |

详见《IP5406电源板设计方案.md》第 9 章。

## 8. 打样与装配

1. 嘉立创下单：2 层、1.5 mm、1 oz 铜、喷锡（HASL），直接上传 `gerber/` 里的
   8 个层文件 + 1 个 job 文件 + 1 个钻孔文件（`IP5406_PSU.drl`），共 11 个
2. J1/J2/J4 孔径 1.0 mm、焊盘 1.6 mm、间距 2.54 mm；J3 孔径 1.0 mm、间距 2.0 mm
3. U1 为 ESOP8 带散热焊盘，建议 SMT；手焊需热风枪，**底部散热盘必须着锡并接 GND**
4. 装配顺序：先贴 U1/L1/电容 → 再焊 J1/J2 排针、J4、J3（PH2.0 座）
5. 上电顺序：先只接 5V 输入验 5V 输出 → 再接电池验充电 → 最后带载拔插测试
   （核心指标：不重启）
6. J4 不接开关时务必插短接帽，否则 5V 输出断开（芯片本身仍正常）
