HA Monitor Display 配置生成器 v3.0

填 WiFi / MQTT + 选 49 个槽位实体 → 下载 secrets.yaml 与 monitor_display_push.yaml，改完即用，无需改代码。

📖 使用前必读：改哪里、要不要重新编译？

本页面给 HA Monitor Display 电子墨水屏/触摸屏 的使用者生成两份配置文件。设备的 49 个数据键名是固件与 HA 约定好的"信箱编号"，永远不用改——你只需要决定"每个信箱收哪个 HA 实体的数据"。 改动后的数据流：HA 实体 → 自动化每5秒打包 JSON → MQTT → 屏幕，实体 ID 不会进入固件。

你改了什么替换哪个文件要重新编译烧录吗如何生效
只换某些槽位的实体
（最常见）		 monitor_display_push.yaml
→ 覆盖 HA 的 /config/packages/ 同名文件		 不需要 HA 左下角 开发者工具 → YAML → 自动化 点"重新加载"即可，几秒内屏幕数据刷新
WiFi / MQTT 服务器 / 各类密码 secrets.yaml
→ 覆盖 ESPHome 的 /config/esphome/secrets.yaml		 需要 ESPHome 里对设备点 INSTALL 重新编译烧录（可先 VALIDATE），设备重启后生效
首次安装设备 两份文件都替换 需要 按仓库 README 完成首次烧录，之后日常调整只走第一行
  • 下载的文件在浏览器的"下载"文件夹（Windows 在 C:\Users\你的用户名\Downloads），同名文件重复下载会自动加 (1) 后缀，注意别拿错旧版。
  • 替换前建议把旧文件复制一份留底；填错了随时可从本页重新生成，最坏情况也只是个别字段显示 -- 或 unknown，不会损坏任何东西。
  • 槽位留空：屏幕对应位置显示 "--"，完全合法，用不到的功能就空着。
  • 实体类型不符（标红）：仍然可以保存，但该字段可能显示 unknown 或乱值——见各组开头的"取值说明"，带 属性取值 标记的槽位对实体要求最严格。
  • 长期访问令牌等同于你的 HA 账号权限，只保存在本浏览器，不会上传；用完可在 HA 个人资料里随时撤销。

1基础配置（secrets.yaml）

这 9 个键与设备固件 ha-monitor-display.yaml 的 !secret 引用一一对应，键名不可改。「随机」按钮生成高强度密码。

2连接 HA 自动填实体（可选）

把本页放到 HA 的 /config/www/ 后经 http://HA地址:8123/local/monitor-display-generator.html 打开（同源直连，无跨域）。 令牌在 HA 个人资料 → 安全 → 长期访问令牌 创建，只读即可用。不填也能用第 3 步手填。

3槽位实体（49 个）已填 0/49

键名是屏幕固件约定，不可改；右边填你 HA 里的 entity_id。顺序按屏幕版面排： 第 1 页→第 2 页，行内从左到右、从上到下（系统页/通知页不使用数据槽位）。sensor 等标签是期望类型，填其他类型会标红提示（仍允许保存）。 留空的槽位屏幕对应位置显示 “--”，不会报错。
